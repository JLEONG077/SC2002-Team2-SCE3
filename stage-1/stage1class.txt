note as N1
  Stage 1: base game. Customer is abstract with hook methods (lossPerTurn, discount, chooseItem) so later stages only add subclasses.
end note
note as N2
  Customer: POLYMORPHISM. lossPerTurn(), discount() and chooseItem() are overridden in subclasses, so no type checks are needed in the controller.
end note
note as N3
  Order: ENCAPSULATION. status and progress are private and change only through advance(), markServed(), markPaid() and cancel().
end note
note as N4
  Restaurant: COMPOSITION. Tables and staff live and die with the Restaurant. Customers are only aggregated, as they come and go.
end note
